# reference — замороженный эталон

Гейты ZCode-эпохи (`gates/`), их тесты (`tests/`) и исторический
`gates/hooks.json` — эталон паритета для нативного плагина `dsh-1c-contour`
(тикеты T2–T4). В поставку не входит, в проекты не мапится; удаляется в T8
после паритета и пилота. Правки эталона запрещены: он фиксирует поведение,
которое переносится.
