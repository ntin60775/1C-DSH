Переведи проект со старой zcode-раскладки на `.dsh/1c`.

1. Аргумент после команды — корень проекта (пусто — cwd). Убедись, что
   это 1С-проект; состояние перевода покажет `--check` на шаге 2.
2. Прогони проверку: 0 — «переведён и совпадает», 1 — «не переведён»,
   2 — «переведён с расхождением» (дифф в stderr).

   ```bash
   python3 "$DSH_1C_ROOT/scripts/migrate_from_zcode.py" <корень> --check
   ```

3. Покажи план переноса: тот же вызов с `--dry-run` — список файлов,
   ничего не меняя.
4. После подтверждения пользователем — без флага. Скрипт переносит
   раскладку и входы гейтов; git-коммиты делает агент, не скрипт.

   ```bash
   python3 "$DSH_1C_ROOT/scripts/migrate_from_zcode.py" <корень>
   ```

5. Сверь `--check` == 0 и прогони `/1c-doctor`.
6. Ворктри проекта мигрируются тем же скриптом по каждому дереву
   отдельно.
