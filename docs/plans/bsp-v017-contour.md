# Спека: граница БСП v0.17 в контуре 1C-DSH

> Гейт 1 (22.11): скоуп сужен оператором — «задача только привести в порядок
> 1C-DSH». Зеркало `1c-ssl-skills` и вендоринг в проекты из юнита исключены;
> что о них известно — в `tickets/bsp-v017-sync/critic-triage.md`.
>
> Гейт 2 (22.11): правки по триажу проекций — линтер меряет декодированное
> значение, тексты скиллов получают границу v0.17, док-гниль про пресет `1c`
> снимается, носители доказательств падающие.

## Цель

Контур знает про границу БСП v0.17: чисто платформенная задача не требует
скилла `bsp`, ошибка у поля формы и `Отказ` ведут в `base-common.md`, явное
ревью API БСП перекрывает исключение. Линтер слотов судит фронтматтер так же,
как DSH (по декодированному значению `yaml`-скаляра), поэтому escaped-запись
из апстрима проходит без раскодирования. Документы контура не обещают
снятого пресета `1c`.

## Рамки

- Только репозиторий `1C-DSH`. Зеркало `1c-ssl-skills` (мерж, тег `v0.17.1`,
  push), вендоринг в проекты парка и правка `consumers.plugins` — не этот
  юнит; материал по ним оставлен в `tickets/bsp-v017-sync/critic-triage.md`.
- Гейты, доставка, пресеты, doctor, раскладки, состояние — без правок.
- Тело и `references` скилла `bsp` контур не содержит: это чужой пак, живёт в
  проекте.
- Историю (`docs/ops/`, `docs/plans/` прошлых юнитов, `tickets/`) не правим.

## Ограничения

- Линтер считает декодированную длину; у апстримного описания v0.17 это 736
  символов, сырой escaped-скаляр — 1098. Предел 1024 — каталог DSH.
- Док-гниль правится по факту файлов репозитория (`src/delivery/config.ts`,
  `cordis.patch.yml`), а не по историческим записям.
- Правка канона (`1c-contour`, `1c-bsl-review-standards`) требует прохода по
  `docs/TEXT-STYLE.md` и приёмки формулировки оператором.
- Полный python-набор долгий (`tests/test_stale_lock_orphans.py` ≈ 2м11с);
  гоняется перед коммитом, а не в каждом шаге.

## Контекст

Апстрим `brake71/1c-ssl-skills` v0.17 (`579d8a4`) сузил активацию скилла:
правка свойства элемента формы — платформенная задача без БСП; ошибка у поля
формы и `Отказ` при стандартных подсистемах → `base-common.md`; явное ревью
API БСП перекрывает исключение; в `references/users-access.md` появился полный
пример RLS-отказа (`ЧтениеРазрешено` + `СообщитьПользователю(...,
"Объект.ДокументОснование", , Отказ)`).

Контур от версии пакета не зависит: `deploy.json`/doctor проверяют путь
`.dsh/1c/skills/bsp`, а описание и триггер приходят из фронтматтера пакета.
Что мешало и починено: линтер мерил сырую строку (escaped-описание апстрима
1098 > 1024) и тем принуждал раскодировать `description` в кириллицу;
документы контура обещали пресет `1c`, снятый в 0.2.0 (`cordis.patch.yml`
держит только строку `1c-contour`, `src/preset/` нет, доставка живёт в
`src/delivery/`).
