«Стартуй юнит» — открыть draft-спеку юнита (скилл `grilling`); «исполняй
тикет N» / `/ship` — ship тикета N, один тикет за запуск. Чек-лист
фазовых переходов: вычитка спеки перед план-гейтом — `grilling`; нарезка
и критик — `to-tickets`; ревью-панель перед merge — `ship`. Состояние
брать из этого файла, следующий тикет — отсюда же.
