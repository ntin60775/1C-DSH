## Открытая работа

Спека утверждена, тикеты не нарезаны. Следующий шаг — нарезка: скилл
`to-tickets` вызывает оператор. После приёмки последнего тикета агент сам
запускает критика плана (один прогон на юнит), затем ship.

## Порядок тикетов

Пусто — нарезка впереди; порядок появится здесь после to-tickets.

## Что осталось

Этапы 2–7 спеки #37 — отдельными юнитами после этапа 1: wire_config +
MCP-записи, doctor, run_e2e/sweep/publish, скиллы/доки, тесты, живая приёмка
на двух базах. Условие возврата: каждый следующий юнит открывается после
закрытия предыдущего по правилу «задачу закрывает только владелец».

## Стартовый промпт

«Стартуй юнит» — открыть draft-спеку юнита; «исполняй тикет N» — ship
тикета N. Чек-лист фазовых переходов: вычитка спеки перед план-гейтом —
скилл `grilling`; критик после нарезки — скилл `to-tickets` запускает
оператор, ревью-панель перед merge — скилл `ship`.
