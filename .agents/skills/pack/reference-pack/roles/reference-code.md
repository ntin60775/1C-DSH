# reviewer-reference-code — эталонный чек-лист (пример)

Минимальный пример чек-листа роли пака для контракта API v1.

## Область

Код диффа изменения и стандарты пака `standards/reference-standards.md`.

## Чек-лист

- каждый пункт стандартов пака проверен по диффу; нарушение названо
  местом и правилом;
- имена и стиль читаются как окружение: второй стиль рядом с
  существующим — находка;
- отклонение от стандарта без названной причины — находка.
