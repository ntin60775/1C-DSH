# Эталонные стандарты (пример пака команды)

Минимальный пример файла стандартов для контракта пака API v1.
Правила ниже — образец формы, не нормы проекта: у каждого правила
назван носитель проверки.

## Форма правил

- Правило формулируется проверяемо: что именно считается нарушением.
  Носитель проверки — чек-лист роли или механический гейт.
- Правило без носителя и проверки — заявка: она не действует, пока не
  получила носителя.
- Отклонение от правила называется в отчёте с причиной; молчаливое
  отклонение — нарушение.

## Пример правила

- Имена и стиль кода читаются как окружение: новый код не вводит
  второй стиль рядом с существующим. Носитель проверки — чек-лист
  роли `reviewer-reference-code`.
