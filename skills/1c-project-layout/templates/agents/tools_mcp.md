# Каталог tools/mcp — MCP-тулкит для 1c-db

Обработка 1c-mcp-toolkit под ОС хоста: Linux → `MCP_Toolkit_linux.epf`,
Windows → `MCP_Toolkit.epf`, macOS → `MCP_Toolkit_macos.epf`. Источник —
клон тулкита (build/) или релиз того же тега; раннер `start_1c_db.sh`
выбирает файл по ОС и доставляет отсутствующий сам (v0.4.51).

## Правила
- В git не попадает (см. `.gitignore`); обновляется через навык
  `1c-db-data` (раздел «Обновление обработки (epf)» — подтверждение
  доверия к контенту, три пути).
- Инстансы мультистенда держат копии обработки отдельно:
  `build/.1c-db-autostart-<имя>/`; при обновлении мастера старые копии
  не перезаписываются — расхождение предупреждается, каталоги инстансов
  обновляются/сносятся руками (скилл `1c-db-data`).
- Свои файлы в этот каталог не класть.
