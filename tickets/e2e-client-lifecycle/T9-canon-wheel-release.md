# Т9 «Канон и поставка wheel»

Оценка: ~50 мин. Блокеры: Т2, Т3, Т6.

## Зачем

Код без канона возвращает проекты к прозе «механику повторяет сам»:
раздел «GUI-тесты соло» в 1c-test-contour описывает ручной рецепт, а
плагин с новым слоем не доедет до venv проектов без релиза wheel и пина.
Фикстура появилась — рецепт обновлён тем же тикетом.

## Что делается

- Скилл 1c-test-contour: раздел «GUI-тесты соло» — фикстура `solo_base`
  из коробки вместо ручного рецепта; pgrep-диагностика заменена на
  `--status`/плагиновую сборку (помеченная небезопасной в Т6 — заменена).
- Словарь testpilot (скилл 1c-testpilot): обход F7 — raw-вызов
  `testpilot.call("click", key=..., handle=...)` от свеженайденного
  элемента; библиотечной правки нет (AGPL, правки вендора запрещены).
- `skills/1c-project-layout/templates/e2e/test_contour_basics.py` —
  пример соло-фикстуры (реальный носитель — каталога `templates/e2e/`
  от корня репо нет, находка критика P2-1; правится вместе с
  scaffold.py и tests/test_project_layout.py, которые шаблон знают).
- Поставка: релиз wheel `1c_onec_db` минорным бампом (соло-фикстура,
  финализация, сборка диагностики), дефолт `ONEDB_PIN` в
  `scripts/install_testpilot.sh` обновлён (`ONEC_DB_PIN` — env-override,
  дефолтный URL живёт в `ONEDB_PIN`; находка критика P3-2), смок venv
  после установки пина.

## Демо-путь

Свежий venv по обновлённому пину: импорт соло-фикстуры и маркера из
плагина; грепы скилла показывают `solo_base` и `--status`; шаблон
собирается.

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: грепа скилла 1c-test-contour — в разделе соло-режима есть
   «плагин 1c_onec_db» и «--status», пилотная формулировка «в пилоте —
   фикстура solo_base» заменена (слово `solo_base` в скилле уже есть на
   базовом дереве и маркером падения не служит — находка критика P3-3).
   На базовом дереве — падает.
2. Артефакт: грепа словаря testpilot — обход F7 (raw-вызов click).
   На базовом дереве не проверено, есть ли запись (сверить в ship;
   если запись уже есть — инвариант, факт фиксируется в тикете).
3. Артефакт: грепа
   `skills/1c-project-layout/templates/e2e/test_contour_basics.py` —
   пример с `solo_base`. Падает на базовом дереве.
4. Артефакт: смок свежего venv — установка по обновлённому дефолту
   `ONEDB_PIN`, импорт `solo_base` и `e2e_solo` из плагина. На базовом
   дереве пин 0.1.6 — падает.
5. Артефакт: `python3 scripts/lint_skill_frontmatter.py` зелёный после
   правок скиллов (инвариант).

## Границы

- Спека п. 9 поправлена словом оператора 06.11: путь шаблона — реальный
  носитель, пин — дефолт `ONEDB_PIN`; тикет ведёт реальный носитель.
- Библиотечная правка `Element.click` (апстрим testpilot 1.9.2) — вне
  юнита по Рамкам спеки: репорт апстриму и канон обхода, не патч.
- Релиз субрепо `1c-onec-db` — обычный wheel-релиз, не контурный тег
  v0.4.x; пин обновляется в том же тикете (фикстура и пин одним заходом,
  по образцу конвенции «скилл и mapping одним коммитом»).
