# Т3 «Докстринги onec_db: границы execute-окружения»

Оценка: ~20 мин. Блокеры: Т1, Т2.

## Зачем

Пользователи фикстур читают границы окружения Выполнить в докстрингах
(`1c-onec-db/src/onec_db/core.py`): прецедент — `create_object` уже несёт
границу «Новый(Тип(...)) ломает установку реквизитов». Ишью 58 показало:
границы синтаксиса фрагмента (ветвление, циклы, доступность глобальных
функций) нигде не названы — обходы рождаются молча. Правки в main;
релиз wheel — отдельное слово оператора, в юнит не входит.

## Что делается

- Докстринг `execute()`: границы из матрицы Т1 — самодостаточная
  формулировка (правила понятны без скилла: что матрица проверила и что
  осталось «не проверено», счётчик против молчаливого частичного
  исполнения; панель Т1–Т2: классов, падающих или молчащих, матрица не
  нашла — правило «плоских конструкций» в докстринг не заводится);
  ссылка на скилл 1c-test-contour — как дополнение для читателей
  контура (onec-db используется и вне zcode — межрепо ссылка не несёт
  матрицу).
- Докстринги `create_object`/`delete_object`: сверить существующую прозу
  с матрицей — помощники уже плоские и однострочные; если матрица
  добавляет грань (например доступность функций), дописать одной строкой.
- README onec_db — только если там есть проза про синтаксис фрагментов;
  без нового раздела.
- Тесты onec_db не меняются (докстринги — проза); прогон зелёным
  подтверждается.

## Демо-путь

`help(OnecDB.execute)` показывает границы до первого падения фрагмента.

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: grep «счётчик» по докстрингу `execute()`. Ожидание: правило
   счётчика против молчаливого частичного исполнения названо
   (правлено по находке панелей Т1–Т2: пре-матричное «правило плоских
   конструкций» матрицей не подтверждено). На базовом дереве — падает.
2. Артефакт: прогон тестов `1c-onec-db/tests/`. Ожидание: зелёные до и
   после (инвариант).
3. Артефакт: сверка докстрингов с матрицей Т1. Ожидание: каждая граница
   подтверждена строкой вывода прогона; сверх матрицы ничего не
   заявлено.

## Границы

- Версия 0.1.7 не выпускается в юните: правки едут в main, релиз —
  отдельное слово оператора (канон «записано не равно выпущено»).
- Фикстуры и сериализация не меняются: только проза докстрингов.
