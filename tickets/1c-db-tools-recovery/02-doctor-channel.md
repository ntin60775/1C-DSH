# Т2 «doctor: канал станции и честный WARN»

Оценка: ~90 мин. Блокеров нет.

## Зачем

doctor сегодня отвечает «сервер 1c-db не отвечает» (`mcp.db-down`) и обещает,
что «до старта стенда инструменты 1c-db в сессии недоступны». После Т1 это
неправда: тулы появятся сами, когда прокси поднимется, — а вот «прокси жив,
клиент 1С не опрашивает канал» doctor не различает вовсе и не проверяет
каналы инстансов. Вызов без клиента висит до 60 с, и это надо называть.

## Что делается

- `scripts/doctor.py`, `check_mcp`: после liveness — проба канала
  `GET <origin>/1c/status?channel=<channel>` для main и для каждого канала
  `db-instances.yaml`. Ответ 200 с `last_seen_at: null` → WARN
  `mcp.db-no-client` с именем канала и подсказкой «тулы есть, вызовы повиснут
  до подключения клиента 1С». Свежий `last_seen_at` — без WARN.
- Там же: эндпоинт недоступен (не прокси тулкита, 404) — проверка канала
  пропускается, вердикт liveness не меняется.
- Ложный текст WARN `mcp.db-down` заменён: обещание «инструменты недоступны»
  снято, вместо него — бюджет реконнекта.
- `tests/test_doctor.py`: HTTP-стаб для `/1c/status` переносится из
  `tests/test_zombie_proxy.py`/`tests/test_start_1c_db.py`; три ветки main
  (null → WARN, свежий → без WARN, недоступен → пропуск) и ветка инстанса
  (WARN с именем канала).

## Демо-путь

`python3 scripts/doctor.py <проект> --json` на фейк-прокси: в разделе `mcp`
строка `mcp.db-no-client` с именем канала; `--json` несёт канал и
`last_seen_at`. На дереве без правки кода проверки нет — прогон красный.

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: `python3 tests/test_doctor.py` — фикстура «прокси жив,
   `last_seen_at: null`» даёт WARN `mcp.db-no-client` с именем канала; на
   базовом коммите тест падает (кода нет).
2. Артефакт: тот же тест — свежий `last_seen_at` не даёт WARN; эндпоинт 404
   не меняет вердикт liveness. Ожидание-инвариант: зелёный до и после для
   liveness-ветки.
3. Артефакт: тот же тест — канал инстанса из `db-instances.yaml` даёт WARN с
   его именем; на базовом коммите падает.
4. Артефакт: `grep -n "в сессии недоступны" scripts/doctor.py` — 0 вхождений;
   новый текст называет бюджет реконнекта. На базовом коммите падает.

## Границы

- Liveness (`http_alive`) и `--no-ping` не меняются.
- Каналы инстансов только читаются из `db-instances.yaml`, состав и коллизии —
  прежняя проверка.
- Живая проба канала — Т5, не здесь.
