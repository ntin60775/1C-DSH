# Т3 «`--status`: группа канала»

Оценка: ~60 мин. Блокеров нет.

## Зачем

`start_1c_db.sh --status` показывает владельца порта, процессы с базой, лок
`1Cv8.1CL` и stand-замок, но не отвечает на вопрос «клиент 1С опрашивает
канал или нет». В сценарии issue это и есть различие между «вызовы работают» и
«тулы есть, вызовы висят до 60 с».

## Что делается

- `scripts/db_status.py`: новая группа «канал» после группы stand-замка.
  Проба `GET <origin>/1c/status?channel=<channel>` с коротким таймаутом, только
  когда владелец порта — прокси тулкита; иначе строка «канал: не прокси
  тулкита».
- Поля в группе — как в ответе прокси: `last_seen_at` и
  `last_seen_seconds_ago` (не `seconds_ago`). Живой клиент — значение и
  «секунд назад»; `null` — «клиент не опрашивает канал»; прокси молчит —
  «канал: прокси не отвечает».
- `tests/test_db_status.py`: три ветки — живой канал с клиентом, живой без
  клиента, прокси не отвечает; плюс владелец порта не прокси. Существующие
  побайтовые сравнения вывода обновляются под новую группу.

## Демо-путь

`bash scripts/start_1c_db.sh . --status` на живом прокси без клиента печатает
группу «канал» с `last_seen_at: null`; с клиентом — свежее значение. На дереве
без правки группы нет.

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: `python3 tests/test_db_status.py` — вывод `--status` содержит
   группу «канал» с `last_seen_at` и `last_seen_seconds_ago`; на базовом
   коммите тест падает (группы нет).
2. Артефакт: тот же тест — при `last_seen_at: null` строка говорит «клиент не
   опрашивает канал»; при свежем — значение и секунды. Ожидание из спеки.
3. Артефакт: тот же тест — молчащий прокси даёт «канал: прокси не отвечает»,
   команда завершается с прежним кодом; на базовом коммите падает.
4. Артефакт: тот же тест — владелец порта не прокси тулкита: «канал: не прокси
   тулкита», сетевой пробы нет. Ожидание-инвариант: зелёный до и после.

## Границы

- Локальные группы (порт, процессы, лок, stand-замок) не меняются.
- Проба — только чтение; станция и клиент не поднимаются и не гасятся.
- doctor — Т2, живая проба — Т5.
