# Т4 «Канон: живая/холодная сессия, снятие обещаний рестарта»

Оценка: ~45 мин. Блокеры: Т1–Т3.

## Зачем

Скиллы обещают неверное: `1c-kd-rules` — «инструменты могут появиться только
после перезапуска сессии», `1c-db-data` — «до перезапуска инструментов
инстанса в ней нет». `dsh-install.md` о бюджете реконнекта молчит. После Т1–Т3
эти тексты врут: тулы догоняют поднятую станцию без рестарта, а различие
«клиент опрашивает канал» стало видимым.

## Что делается

- `skills/1c-kd-rules/SKILL.md`: фраза «инструменты могут появиться только
  после перезапуска сессии» снята; вместо неё — бюджет реконнекта и «тулы
  появятся после подъёма станции, без перезапуска сессии».
- `skills/1c-db-data/SKILL.md`: развилка «живая/холодная сессия» — живой
  перезапуск стенда рвёт MCP-сессию и восстанавливается сам (существующий
  текст), холодная сессия догоняет поднятую станцию в пределах бюджета; фраза
  «до перезапуска инструментов инстанса в ней нет» снята.
- `docs/dsh-install.md`: абзац в разделе доставки — HTTP-строки несут политику
  реконнекта, погашенная станция не лишает сессию тулов после подъёма, бюджет
  ≈57 мин при мгновенном отказе.
- `docs/dsh-gates.md` не правится: нового входа `contour.json` нет.

## Демо-путь

Грепы литералов: снимаемые фразы — 0 вхождений, добавленные — есть; линт
фронтматтера зелёный; формулировки приняты оператором.

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: `grep -c "только после перезапуска сессии"
   skills/1c-kd-rules/SKILL.md` → 0; текст называет бюджет реконнекта. На
   базовом коммите 1 — падает.
2. Артефакт: `grep -c "до перезапуска инструментов инстанса"
   skills/1c-db-data/SKILL.md` → 0; есть развилка «живая/холодная сессия». На
   базовом коммите 1 — падает.
3. Артефакт: в `docs/dsh-install.md` есть абзац про политику реконнекта HTTP-
   строк и бюджет ≈57 мин; на базовом коммите 0 вхождений — падает.
4. Артефакт: `python3 scripts/lint_skill_frontmatter.py` — зелёный. Сигнал к
   чтению, не доказательство.
5. Артефакт: приёмка формулировок оператором (проход по
   `docs/TEXT-STYLE.md`) — без замечаний.
