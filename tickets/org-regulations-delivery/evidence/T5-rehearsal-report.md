## Названные пробелы и границы (приняты)

- Дефект продюсера OntoShip: `install.sh --copy --pack` копирует
  `.git` орг-репо в пак; чтение git источника для copy обновляет
  index → ложный copy-differs на повторе (цепочка доказана
  оркестратором-3). Followup продюсеру (issue при gh-доступе);
  вне рамок юнита. Текст уточнён: git источника только для link;
  оговорка .git в копии, формат timestamp архива (UTC
  YYYYMMDDTHHMMSSZ) и раскладка cp (подкаталог именем пака) —
  contour-deploy `85eaea1` (ветка t5-clarifications, находки
  холодного исполнителя Т5).
- Copy-акт без коммита источника — граница v1 (канон: commit для
  link); провенанс copy по версии+дате.
- Gitignore-строка `.agents/packs` — поверхность init OntoShip;
  пак-шаг не правит; проекта без OntoShip — названный пробел.
- Субагентный fan-out полного деплоя и живой ask батча — первый
  живой прогон командой оператора (вне приёмки, названо спекой).
- Наполнение регламентов и проза норм — отдельный проход оператора
  (вне юнита).
- Org-репо без remote: PR-путь Т3 не проверен (правило репо).
