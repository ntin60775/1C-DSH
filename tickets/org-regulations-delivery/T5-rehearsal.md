# Т5 «Репетиция и приёмка»

Оценка: ~90 мин. Блокеры: Т1, Т2 (протокол и пак-шаг существуют).
Спека: Готово 6; решения 4, 6; находки T9, T10, T11, T12, T13, T14.

Модели субагентов Т5 (решение оператора 20.11 — не жечь деньги на
тесте): холодный исполнитель и ревью-панель — на дешёвых маршрутах
`deepseek-account/deepseek-flash` уровень `high` и
`qwen-token-plan/qwen3.8-flash` уровень `medium` (уровня high у
qwen3.8-flash нет, взят ближайший дешёвый). Отклонение от реестра
ролей называется в отчёте панели.

## Зачем

Демо Т1/Т2 показывают happy path; приёмка требует полной матрицы
аномалий и изоляции от живых носителей. Риски link-канала (WIP,
write-through, битый манифест) и подмес конторы должны быть
проверены, а не названы. Холодный исполнитель доказывает исполнимость
текста протокола без знаний «из головы».

## Что делается

- Репетиция в /tmp: два temp-орг-чекаута с валидными team-паками
  разных имён + четыре temp git-проекта (ядро OntoShip установлено —
  ожидание `--check` названо); temp-конфиг и temp-реестр через
  параметры протокола; checksum живых конфигов/реестров до/после.
- Матрица сценариев: отсутствие org → один батч-вопрос → запись →
  второй прогон молчит; отсутствие ключа regulations; новый ПК —
  висящий link → relink; установка link и copy; link-обновление
  коммитом (новый текст без действий) и WIP-правкой (мгновенное
  распространение, dirty-маркер); copy-differs → архив+снос+поставка
  без ask; одноимённый relink (подмес конторы); аномалии без записей
  (мёртвый чекаут, невалидный пак, два team-пака, смесь канала);
  битый манифест → `--check` красный + run_gates exit 2; `--dry-run`
  — ноль записей; акты name/version/channel/date; повторный полный
  прогон — тишина.
- Один исполнитель-субагент на одном temp-проекте: холодный агент,
  только текст протокола; шаг «из головы» = дефект текста.
- Отчёт с точными выводами и кодами по каждому сценарию — в
  `tickets/org-regulations-delivery/`; расхождение = дефект.

## Демо-путь

Отчёт приёмки: все сценарии матрицы с выводами команд и кодами,
ожидания спеки совпали; checksum живых носителей не изменились;
холодный исполнитель прошёл протокол по тексту. Краснота на базовом
коммите: протокола и пак-шага нет — матрица неисполнима.

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: отчёт репетиции, сценарии батч/тишина/каналы/акты.
   Ожидание: выводы и коды совпадают с Готово 6 спеки. На базовом
   дереве протокола нет — неисполним.
2. Артефакт: сценарии аномалий (мёртвый чекаут, невалидный пак, два
   team-пака, смесь канала, одноимённый relink, битый манифест,
   dry-run). Ожидание: именованные отказы без записей; битый
   манифест → check красный + run_gates exit 2; dry-run → ноль
   записей. На базовом дереве неисполним.
3. Артефакт: checksum живых конфигов/реестров до/после. Ожидание:
   идентичны (изоляция). Инвариантный критерий: зелёный при
   соблюдении изоляции, падает при правке живого носителя.
4. Артефакт: доклад холодного исполнителя-субагента. Ожидание:
   протокол исполнен по тексту, расхождений нет. На базовом дереве
   текста нет — неисполним.

## Разбор расхождений ожидание/факт

Доказательства Т5: [T5-rehearsal-report.md](evidence/T5-rehearsal-report.md)
(сводная матрица), [T5-rehearsal.sh](evidence/T5-rehearsal.sh) /
[T5-rehearsal.log](evidence/T5-rehearsal.log),
[T5-cold-executor.md](evidence/T5-cold-executor.md),
[T5-cold-executor-2.md](evidence/T5-cold-executor-2.md); матрица
ссылается на доказательства Т1/Т2 в той же папке.

- Сценарий битого манифеста: первая прогона зелёная — sed-паттерн
  скрипта не совпал с JSON без пробела (манифест не ломался);
  исправлен, повтор: --check exit 1 (drift: pack) + run_gates exit 2.
- Сценарий подмеса: фикстура B нарушала контракт (имя каталога ≠ имя
  манифеста) → валидатор отказал; фикстура перенесена в каталог с
  именем пака (другой родитель), повтор: молчаливый relink доказан.
- Холодный исполнитель copy-цикла (qwen3.8-flash medium): цикл
  зелёный; находки — формат timestamp и раскладка cp не заданы,
  .git в копии (дефект продюсера) → уточнения текста pack-deploy
  (85eaea1, 695d796), .git — followup продюсеру.
- Исполнитель-2 (ветки mix/two-team/copy): пробы исполнены по тексту
  (стоп смеси канала доказан inode/mtime + лабораторный контроль
  опасности; отказ двух team без записей); дефекты текста — пустой
  инвентарь разрешает снос (.git-only расхождение), glob-скан
  пропускает мусор (fail-closed не срабатывает), коллизия timestamp,
  project-name не определён → правки безопасности 8558056, проба
  исполнителя-4.
- Исполнитель-3 (мини-проба): негативная проба сноса (архив 000 →
  стоп, цель цела) и финальная раскладка зелёные; находки — архив
  недоступен не в Аномалиях, опасная подсказка установщика, коллизия,
  инвентарь без pyc → 22237d5.
- Исполнитель-4 (пробы безопасности на 8558056): пустой инвентарь →
  стоп без архива (целостность sha256/mtime), мусор → fail-closed
  (shim-детектор: установщик не вызывался), коллизия → суффикс -2
  (коллизионный каталог не тронут) — все по тексту. Находки
  D1–D5/D8 (порядок инвентаря, имя источника, суффикс циклом,
  diff exit 2, дата UTC, newline) → финальные правки a75c658;
  поведение проб не менялось (уточнения формулировок).
- Прочих расхождений не было.
