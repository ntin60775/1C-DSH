# Т1 «pack-deploy: протокол и доставка»

Оценка: ~50 мин. Блокеры: нет. Спека:
[org-regulations-delivery](../../docs/plans/org-regulations-delivery.md),
Готово 1; решения 2, 6; находки T4, T6, T7, T17.

## Зачем

Протокола поставки/обновления регламент-пака на один проект нет:
deliver исключает паки явно (скоп — ядро), источник пака — чекаут
конторы, не ядра. Носитель протокола — отдельный скилл pack-deploy в
репо contour-deploy; без доставки установщиком скилл не попадёт в
глобальный навыковый корень.

## Что делается

- `contour-deploy/skills/pack-deploy/SKILL.md` — протокол одного
  проекта: входы из промпта исполнителя (путь чекаута конторы, канал,
  проект, путь реестра); сверка канала с типом цели до вызова
  установщика (смесь канала — именованная аномалия, copy-режим
  установщика молча заменяет link на copy); `install.sh --pack`;
  отказ «copy differs» → архив старого снимка вне репо с инвентарём +
  снос + типовая поставка без ask (решение 6 спеки); отказ при двух
  team-паках (счёт по `type` манифестов `.agents/packs`); факты акта —
  имя пака, версия (`version` манифеста), канал (из ФС), дата, для
  link коммит чекаута (`git rev-parse --short HEAD`, dirty-маркер);
  доклад оркестратору (запись реестра — не его дело).
- `contour-deploy/scripts/install.sh`: SKILLS-массив пополняется
  `pack-deploy`; `contour-deploy/tests/test_install.py` — тот же
  состав; README contour-deploy — строка маршрутизации.

## Демо-путь

Установщик contour-deploy ставит pack-deploy в навыковый корень
(`test_install.py` зелёный новым составом); линт frontmatter скилла
проходит; прогон протокола на temp-проекте в /tmp: установка link и
copy, copy-differs → архив+замена без вопросов, два team-пака →
именованный отказ. Краснота на базовом коммите: скилла нет в репо —
линт и тест установщика с новым ожиданием падают, прогон протокола
неисполним (нет носителя).

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: вывод `contour-deploy/tests/test_install.py` с ожиданием
   pack-deploy в составе. Ожидание: скилл доставлен, тест зелёный.
   На базовом дереве SKILLS без pack-deploy — тест с новым ожиданием
   красный.
2. Артефакт: вывод `scripts/lint_skill_frontmatter.py` по
   `contour-deploy/skills/pack-deploy`. Ожидание: проход (ключи слотов
   DSH, description ≤ 1024, триггер в первых ~250). На базовом дереве
   файла нет — красный.
3. Артефакт: выводы команд прогона протокола на temp-проекте, кейс
   copy-differs. Ожидание: архив вне репо с инвентарём + чистая
   поставка, вопросов нет; `--check` валидирует пак. На базовом дереве
   протокола нет — критерий неисполним.
4. Артефакт: кейс «два team-пака» — вывод отказа. Ожидание:
   именованный отказ с причиной, записей нет. На базовом дереве
   протокола нет — критерий неисполним.
