# Т1 «pack-deploy: протокол и доставка»

Оценка: ~50 мин. Блокеры: нет. Спека:
[org-regulations-delivery](../../docs/plans/org-regulations-delivery.md),
Готово 1; решения 2, 6; находки T4, T6, T7, T17.

## Зачем

Протокола поставки/обновления регламент-пака на один проект нет:
deliver исключает паки явно (скоп — ядро), источник пака — чекаут
конторы, не ядра. Носитель протокола — отдельный скилл pack-deploy в
репо contour-deploy; без доставки установщиком скилл не попадёт в
глобальный навыковый корень.

## Что делается

- `contour-deploy/skills/pack-deploy/SKILL.md` — протокол одного
  проекта: входы из промпта исполнителя (путь чекаута конторы, канал,
  проект, чекаут OntoShip, корень архива; резолв org→источник — на
  оркестраторе, Т2), сверка `type: team` источника, канал и смесь
  канала до вызова установщика, `install.sh --pack`, отказ «copy
  differs» → архив старого снимка вне репо с инвентарём + снос +
  типовая поставка без ask (решение 6 спеки), отказ при двух
  team-паках (счёт по `type` манифестов `.agents/packs`), факты акта —
  имя пака, версия (`version` манифеста), канал (из ФС), дата, для
  link коммит чекаута (`git -C <source> rev-parse --short HEAD`,
  dirty-маркер `git -C <source> status --porcelain`); доклад
  оркестратору (запись реестра — не его дело).
- `contour-deploy/scripts/install.sh`: SKILLS-массив пополняется
  `pack-deploy`; `contour-deploy/tests/test_install.py` — тот же
  состав; README contour-deploy — строка маршрутизации.

## Демо-путь

Установщик contour-deploy ставит pack-deploy в навыковый корень
(`test_install.py` зелёный новым составом); линт frontmatter скилла
проходит; верификация окружения установщика на temp-проектах в /tmp:
установка link и copy, отказ copy-differs, dry-run, валидатор,
`--check` pack-only проекта; справочный прогон механик протокола
(архив+замена, счёт team-паков, смесь канала). Исполнение протокола
холодным агентом по тексту — Т5 C4. Краснота на базовом коммите:
скилла нет в репо — линт и тест установщика с новым ожиданием падают.

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: вывод `contour-deploy/tests/test_install.py` с ожиданием
   pack-deploy в составе (evidence/T1-tests.log). Ожидание: скилл
   доставлен, тест зелёный. На базовом дереве SKILLS без pack-deploy
   — тест с новым ожиданием красный (evidence/T1-base-red.log).
2. Артефакт: вывод `scripts/lint_skill_frontmatter.py` по
   `contour-deploy/skills` + триггерный тест состава (T1-tests.log,
   мутация «убрать слово регламент» краснит). Ожидание: проход (ключи
   слотов DSH, description ≤ 1024, триггер в первых ~250). На базовом
   дереве файла нет — красный.
3. Артефакт: evidence/T1-demo.log — верификация окружения установщика
   (не новое поведение Т1): link/copy-установка, отказ «copy differs»
   (exit 1), dry-run без записей, валидатор (валиден / отказ exit 2),
   `--check` pack-only проекта: `ok pack` + drifted core, exit 1
   (ожидание названо, Готово 6 спеки). Ожидания — Контекст спеки
   (поведение install.sh OntoShip). Справочный прогон механик
   (архив+замена, счёт team-паков, смесь канала, stack-отказ) —
   референс, не доказательство прозы.
4. Артефакт: текст `skills/pack-deploy/SKILL.md` — шаги протокола
   названы (входы, `type: team`, канал/смесь, `--pack`, замена copy
   с архивом, отказ двух team-паков, факты акта), команды ссылаются
   на существующие install.sh/валидатор. Исполнение протокола
   холодным агентом по тексту — Т5 C4 (названная передача). На
   базовом дереве файла нет — критерий падает.

## Разбор расхождений ожидание/факт

- C3 «--check валидирует пак»: факт — `--check` на pack-only проекте
  красный по скиллам ядра (`ok pack` при этом есть); ожидание названо
  в демо, полный `--check` с ядром — Т5. Валидатор пака показан
  отдельно.
- C4 «отказ печатает скрипт»: справочный прогон механик не зависит от
  текста скилла (P1 reviewer-tests) — доказательство исполнения
  передано Т5 C4 (холодный исполнитель), критерий переформулирован
  на текст протокола.
- Краснота линта на базе: тривиальна (файла скилла нет), покрыта
  base-red test_install; отдельного лога нет — названо.
- Прочих расхождений не было.
