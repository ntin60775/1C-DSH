# Т3 «Орг-репо: носители правил»

Оценка: ~20 мин. Блокеры: Т1 (README маршрутизирует на pack-deploy).
Спека: Готово 4; решения 1, 5; находки T16, T17.

## Зачем

AGENTS.md орг-репо читает агент в орг-репо, не установщик и не проект:
правила для установщика («один team-пак») там без читателя. README
врёт: «--check ловит дрейф» (валидирует контракт, с источником не
сверяет), учит ручному `--pack` мимо fleet-протокола и тегам, которых
нет.

## Что делается

- `org-dev-regulations/AGENTS.md`: правила мейнтейнера — remote нет и
  не будет никогда; правки норм только централизованно; имя репо
  несёт идентичность конторы; коммит после прохода валидатора; пак
  опционален для контура и проектов. Инвариант «один team-пак на
  проект» — носитель pack-deploy (Т1), здесь не дублируется.
- `org-dev-regulations/README.md`: проверка установленных паков —
  `--check` валидирует контракт (дрейф копии ловит только попытка
  установки); обновление — через команду деплоя контура (пак-шаг,
  скилл pack-deploy), ручной `--pack` назван обходом fleet-протокола;
  версия — `version` манифеста, теги не требуются.

## Демо-путь

Коммиты в орг-репо; валидатор пака зелёный; README маршрутизирует
обновление через деплой, ложных утверждений про `--check` нет.
Краснота на базовом коммите: AGENTS.md без правил мейнтейнера и
README с ложным «дрейф ловит --check» — ожидания текстов падают.

## Критерии приёмки (падают на базовом коммите)

1. Артефакт: текст AGENTS.md орг-репо. Ожидание: правила мейнтейнера
   (remote, централизованные правки, идентичность имени, коммит после
   валидатора); инвариант одного team-пака отсутствует (носитель —
   протокол). На базовом дереве формулировки иные — ожидание падает.
2. Артефакт: текст README орг-репо. Ожидание: `--check` = контракт,
   обновление через команду деплоя, без тегов; строка «дрейф ловит
   --check» отсутствует. На базовом дереве ложная строка есть —
   ожидание падает.
3. Артефакт: вывод валидатора пака по орг-репо. Ожидание: `✓ пак
   org-dev-regulations (team, <версия>) валиден`. Инвариантный
   критерий: зелёный на базе, падает при мутации манифеста.
