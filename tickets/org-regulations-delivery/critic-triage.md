## Спорное — оператору

T8 (власть на тихую замену copy-копии): решение оператора 20.11 —
**архив+замена без ask**. Copy — снимок канона; обновление = архив
старого снимка вне репо с инвентарём + чистая поставка. Полномочие
явное, обратимо (архив), соответствует требованию тихого обновления.
В спеке фиксируется как решение оператора, не тривиальная развилка;
посылка «дрейф = дефект» снята — copy-differs есть штатный путь
обновления copy-канала.
